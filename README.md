One line, at most 120 characters: the funniest voicemail greeting a cat would record. Mittens is asleep on your laptop — leave a message after the beep and she will hear it at 4 a.m. and ignore it.

## Run it

```sh
python3 main.py
```

The program writes the greeting to `/output/entry.txt`.
